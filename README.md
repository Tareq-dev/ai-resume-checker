**AI Resume Checker**

An AI-powered resume analysis platform that helps users evaluate and improve their resumes for Applicant Tracking Systems (ATS).

**✨ Features**

- 📄 Upload and parse PDF resumes
- 🤖 AI-powered analysis using Google Gemini
- 📊 ATS score with score breakdown
- ⚠️ Detect resume issues
- 💪 Highlight resume strengths
- ✍️ Generate improved resume bullet points
- 🔑 Identify present and missing keywords
- 🔄 Create improved resume versions
- 🕘 Resume history and version tracking
- 📥 Export improved resumes as PDF
- 🔐 JWT-based authentication
- 📱 Responsive user interface

**🚀 How It Works**

1. Upload a PDF resume.
2. Resume information is extracted and structured.
3. Google Gemini analyzes the resume.
4. The system generates an ATS score, strengths, issues, keywords, and improvement suggestions.
5. Users can apply AI-generated rewrites.
6. Improved resume versions are saved.
7. Users can preview and export their improved resume as PDF.
